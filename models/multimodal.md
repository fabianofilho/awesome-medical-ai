# Modelos Pré-treinados — Modelos Multimodais

| Modelo | Descrição | Link |
|--------|-----------|------|
| **UniMedVL (ICML 2026)** | Modelo fundacional unificado de visao e linguagem medica com arquitetura Observation-Knowledge-Analysis inspirada no raciocinio clinico; suporta VQA, geracao de laudos, sintese de imagens e traducao cross-modal em 9 modalidades. Aceito no ICML 2026. Dataset UniMedVL-5M (5,6M instancias) disponivel no HuggingFace. | [GitHub](https://github.com/uni-medical/UniMedVL) / [HuggingFace](https://huggingface.co/General-Medical-AI/UniMedVL) |
| **Chai-2 (2026)** | Primeiro sistema de IA para design de anticorpos funcionais de novo contra alvos arbitrários, sem triagem laboratorial. Taxa de sucesso 16–20% (100x melhor que métodos anteriores). Parceria com Eli Lilly; US$130M Series B. (Chai Discovery) | [Chai Discovery](https://www.chaidiscovery.com/) |
| **Merlin (2026)** | Modelo de fundação 3D visão-linguagem para TC abdominal, treinado em +6M imagens e relatórios radiológicos. (Stanford MIMI) | [GitHub](https://github.com/StanfordMIMI/Merlin) |
| **BiomedCLIP** | Modelo de visão-linguagem contrastivo para o domínio biomédico. | [HuggingFace](https://huggingface.co/microsoft/BiomedCLIP-PubMedBERT_256-vit_base_patch16_224) |
| **MedCLIP** | Modelo CLIP adaptado para imagens médicas e texto clínico. | [GitHub](https://github.com/RyanWangZf/MedCLIP) |
| **LLaVA-Med** | Modelo multimodal de linguagem e visão para biomedicina. | [GitHub](https://github.com/microsoft/LLaVA-Med) |
